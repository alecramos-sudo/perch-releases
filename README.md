# Perch releases

Signed builds and the Sparkle update feed for Perch, a macOS menu bar manager.

- Feed: https://alecramos-sudo.github.io/perch-releases/appcast.xml
- Builds: the [Releases](https://github.com/alecramos-sudo/perch-releases/releases) page. Each zip is notarized and signed with Developer ID.

Perch includes code ported from [Ice](https://github.com/jordanbaird/Ice) and is licensed under the GPL-3.0. To request the corresponding source code, open an issue in this repository.
